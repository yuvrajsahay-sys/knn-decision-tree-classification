# KNN vs Decision Tree Classification

## Project Overview
This project explores and compares two supervised machine
learning classification algorithms:

1. K-Nearest Neighbours (KNN)
2. Decision Tree Classifier

The models will be trained using the Breast Cancer Wisconsin
(Diagnostic) dataset.

## Objectives
- Understand supervised classification.
- Implement KNN using Scikit-learn.
- Understand distance metrics and feature scaling.
- Implement Decision Trees.
- Explore Gini impurity and entropy.
- Evaluate and compare model performance.

## Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Breast Cancer Wisconsin (Diagnostic).

Source: https://www.kaggle.com/datasets/uciml/breast-cancer-wisconsin-data

## Project Structure
- notebooks/: ML implementation
- data/: Local dataset (not uploaded to GitHub)
- README.md: Project documentation
- requirements.txt: Dependencies
